# GHVC9 Milestone 2 start — 2026-11-09

Milestone 2 is **not complete**. Version remains 0.9.0-beta.1; the <180 MiB
Test A objective has not been achieved.

## Accepted reliability changes

- Bound the shared GHVC8/9 motion shortlist before appending. A zero nonzero
  finalist budget previously never met its post-append exit condition and could
  overflow the eight-element array when motion search was enabled. Normal
  Balanced settings are unaffected. The default veryfast preset has range zero,
  so its normal invocation did not trigger this issue.
- Add a native CTest for limits 0/1/7, range 12, partial macroblocks, decoder
  reconstruction, and zero-budget equivalence to zero-range reconstruction.
- Compare generated version text with universal newline handling. A Windows
  checkout using CRLF previously failed the byte comparison after the generator
  wrote LF, even though metadata was current. Content mismatches still fail.
- Ignore alternate native build directories. The old build cache referred to
  the repository's former location; configure a fresh `native/build_m2` tree.

## Rejected: coefficient Rice rate in motion RD

An isolated encoder-only prototype replaced GHVC8 byte-token rate estimates
with GHVC9's six-bit last position, capped-unary runs, and Rice k=2 level costs.
Distortion was scaled by eight to retain the original rate/distortion weight.
The syntax, quantization, and shortlist were unchanged.

Same existing 302-frame `test_a_30s_10s.mp4`, Balanced q78, full CRC and quality:

| Metric | Baseline | Prototype |
|---|---:|---:|
| Bytes | 16,411,936 | 16,493,011 |
| Encode fps | 138.260 | 142.587 |
| Decode fps | 796.221 | 662.470 |
| PSNR dB | 45.376 | 45.383 |
| SSIM | 0.982247 | 0.982276 |

Output grew **0.494%**, with only a small quality increase. Reject and remove
the prototype. Speed readings are single runs, with different build provenance
between the existing baseline executable and rebuilt prototype; they do not
establish a performance improvement or regression. No B/C escalation justified.
